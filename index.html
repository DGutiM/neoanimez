Aviso
NeoAnimeZ es un proyecto independiente y no representa a servicios oficiales de terceros. Si alguna información necesita corrección o retirada, puedes contactar por correo.
Seguridad y privacidad
Aquí puedes consultar de forma resumida cómo se gestiona el acceso a cuentas, el uso de datos básicos y las condiciones generales de uso de NeoAnimeZ.
Seguridad de cuenta

NeoAnimeZ utiliza autenticación gestionada mediante Supabase Auth para el registro y acceso de usuarios.

Las contraseñas no se almacenan en texto visible. El acceso a la información personal de cada cuenta se limita mediante reglas de seguridad para que cada usuario solo pueda consultar y modificar sus propios datos dentro de la plataforma.

Aunque se aplican medidas técnicas razonables, ningún sistema conectado a internet puede garantizar seguridad absoluta. Por ello, se recomienda usar una contraseña robusta y no reutilizar contraseñas sensibles de otros servicios.

Política de privacidad

NeoAnimeZ recoge únicamente los datos necesarios para el funcionamiento de la cuenta y de la lista personal del usuario.

Datos utilizados: correo electrónico de acceso, estados de seguimiento, puntuaciones, progreso de episodios, perfil público opcional y mensajes publicados voluntariamente en el tablón de comunidad.

Finalidad: permitir el inicio de sesión, mantener la lista personal, guardar puntuaciones y progreso, mostrar tops de comunidad con datos agregados y habilitar conversaciones públicas dentro del tablón.

Las puntuaciones individuales se asocian a la cuenta para que cada usuario pueda modificarlas o borrarlas. El top público de comunidad debe usar resultados agregados por anime, no listados públicos de usuarios.

Los mensajes del tablón son públicos, pero se muestran con alias de comunidad y no con el correo electrónico del usuario.

La lista compartida solo se muestra si el usuario activa voluntariamente su perfil público. El correo electrónico no se muestra en ese perfil.

NeoAnimeZ no vende datos personales ni utiliza la información de cuenta con fines comerciales ajenos al funcionamiento de la web. Si el usuario deja de utilizar el servicio, podrá dejar de acceder a su cuenta en cualquier momento.

Cookies y analítica

NeoAnimeZ puede usar Google Analytics para conocer actividad general de la web, como visitas, páginas consultadas y datos técnicos aproximados de navegación.

La analítica solo se activa si el usuario acepta las cookies de analítica desde el aviso mostrado en la web. Si se rechazan, la web sigue funcionando igualmente.

La preferencia de aceptar o rechazar se guarda en el navegador para no preguntar en cada visita.

Términos de uso

NeoAnimeZ es una plataforma orientada a la consulta y organización personal de contenido relacionado con anime.

El usuario se compromete a no utilizar la web con fines ilícitos, a no intentar acceder a datos de terceros y a no interferir intencionadamente en el funcionamiento del servicio.

La información mostrada puede proceder de fuentes externas, traducciones o adaptaciones propias de NeoAnimeZ, por lo que pueden existir errores, diferencias de criterio o cambios con el tiempo.

El uso continuado de la plataforma implica la aceptación de estas condiciones básicas de uso.
